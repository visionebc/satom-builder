Publisher key

This installation signs every package it builds with its own Ed25519 publisher key. A SATOM that has registered the public half under Trusted publishers treats those packages as signed: views and widgets land in testing instead of draft. A publisher can never sign code.

Register on a SATOM target

Registering calls SATOM's POST /api/v1/builder/publishers with your token. SATOM accepts it only from a token with scope admin whose owner is a super-admin. The call is idempotent: registering the same key again returns the existing key_id. A super-admin can also paste the public key above into SATOM by hand.
