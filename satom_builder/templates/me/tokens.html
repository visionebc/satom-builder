My SATOM tokens

Everything the Builder does in a SATOM runs with your own SATOM API token, so it carries your RBAC and your ADOM, and SATOM's audit log names you. Create the token in SATOM (Profile › API tokens). Scopes: read to see the target, write to validate and rehearse, admin (as a super-admin) to import and to register the publisher key.

Tokens are encrypted at rest and never shown again: this page only says whether one is set.
