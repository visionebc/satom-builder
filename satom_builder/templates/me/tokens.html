My SATOM tokens

Everything the Builder does in a SATOM runs with your own SATOM API token, so it carries your RBAC and your ADOMs, and SATOM's audit log names you. Create it with the Global ADOM: the Builder then sees the datasets of every ADOM you may enter, and each project installs in the ADOM of the datasets it reads (in Global when it reads more than one). A token bound to one ADOM only ever sees that ADOM. A SATOM administrator with users.manage creates it under Administrator → API Tokens with you as its owner (it is shown once). Scopes: read to see the target, write to validate and rehearse, admin (as a super-admin) to import and to register the publisher key.

Tokens are encrypted at rest and never shown again: this page only says whether one is set.
