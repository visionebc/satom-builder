Two adapters. Anthropic uses the official SDK (default model claude-opus-5-5, streaming, the author guide cached as the fixed system block). OpenAI-compatible covers OpenAI, Azure OpenAI, Mistral, Gemini's compatible endpoint, Ollama, vLLM and LM Studio: give the base URL that ends before /chat/completions (for example https://api.openai.com/v1 or http://127.0.0.1:11434/v1); local servers need no key. Keys are encrypted at rest and never shown again.

Context window. A request carries SATOM's author guide (about 5,000 tokens) plus the target's schema: about 7,000 tokens for a view and up to 30,000 for an app. Hosted models have room. A local server truncates silently at its own default (Ollama: 2,048–4,096 tokens), and the model then never sees the output contract. Start Ollama with OLLAMA_CONTEXT_LENGTH=32768 or more, or the equivalent setting of your server.
